## About The Project

Social Calendar is designed to remove the endless back-and-forth of organising catch-ups. Instead of long message threads, users can share availability and instantly see overlapping free dates.

This project also acts as a practical learning experience for building mobile apps with TypeScript and React Native using Expo.

**Key Features:**

- Shared Availability: Add and manage your free dates.
- Group Coordination: Compare schedules with friends to find overlaps.
- Clean Mobile UI: Simple, focused design built for usability.
- Learning Focused: Built as a TypeScript + React Native (Expo) practice project.

## Getting Started

### Prerequisites

- Node.js (LTS recommended)
- Expo CLI

```bash
npm install -g expo-cli
```

### Installation

1. **Clone the repo**

```bash
git clone https://github.com/GalaxiMaster/social-calendar
```

2. **Install dependencies**

```bash
npm install
```

3. **Start the development server**

```bash
npx expo start:android
```

## Usage

The Social Calendar workflow is simple:

1. Create or join a group.
2. Add your available dates.
3. View overlapping availability with friends.
4. Lock in a date and plan your hang-out.
